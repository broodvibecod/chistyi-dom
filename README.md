# Чистый Дом

Адаптивный коммерческий сайт: React 19, TypeScript, Tailwind CSS 4, Framer Motion, Vite. Исходники и готовая сборка включены. Доставка заявок подключается отдельно, без секретов в браузере.

## Запуск

Установите Node.js 22.18+ с npm. В каталоге проекта:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Для статического хостинга загрузите содержимое `dist`. Для Netlify/Vercel: build `npm run build`, output `dist`. Сайт не требует SPA-rewrite: используются якоря на одной странице. `.openai/hosting.json` относится только к текущей копии Sites; при передаче другому владельцу его нужно удалить и зарегистрировать новый сайт.

## Изменение содержания

- `src/config.ts`: название, контакты, график, адрес, URL встроенной карты, фотографии, услуги, тарифы, минимальная стоимость, дополнения и FAQ.
- `src/main.tsx`: тексты первого экрана, преимуществ, этапов, примеры отзывов, форма и шаблон политики.
- `src/style.css`: палитра, типографика и адаптивная компоновка.
- `index.html`: заголовок, description и Open Graph. После выбора домена добавьте canonical и og:url, абсолютный og:image, sitemap.xml и robots.txt. Не добавляйте вымышленные рейтинги в Schema.org.

Пустые телефон/мессенджеры не создают неработающих ссылок. Введите phone в международном формате, telegram как username без @, whatsapp как номер только из цифр. Для карты используйте разрешённый HTTPS embed URL поставщика карт. Проверьте его на выбранном домене.

Расчёт: max(площадь × тариф, минимальная стоимость) + дополнения. Для окон вместо площади число створок, для мебели число посадочных мест. Комнаты собираются для согласования, доплаты за них нет. Дата желаемая, без проверки занятости календаря. Сервер помечает переданный клиентом расчёт как предварительный, не как обязательную цену заказа.

## Подключение заявок через Telegram

1. Создайте бота через BotFather и получите токен. Начните диалог с ботом или добавьте его в рабочую группу; определите chat_id.
2. Создайте Cloudflare Turnstile widget для домена сайта. Сохраните site key и secret key. Это обязательная защита для предлагаемого обработчика.
3. Установите Wrangler: `npm install --save-dev wrangler`. В `server/wrangler.jsonc` задайте уникальное имя Worker и точный `ALLOWED_ORIGIN` (например `https://example.ru`, без завершающего /).
4. Добавьте секреты командами (значения вводятся интерактивно, не храните их в репозитории):

```sh
npx wrangler secret put TELEGRAM_BOT_TOKEN --config server/wrangler.jsonc
npx wrangler secret put TELEGRAM_CHAT_ID --config server/wrangler.jsonc
npx wrangler secret put TURNSTILE_SECRET_KEY --config server/wrangler.jsonc
npx wrangler deploy --config server/wrangler.jsonc
```

5. В `src/config.ts` укажите `endpoint` (HTTPS URL Worker) и `turnstileSiteKey` (публичный ключ). Пересоберите и опубликуйте сайт.
6. Замените шаблон политики, задайте реального оператора и реквизиты, согласуйте условия передачи данных внешним сервисам. Удалите демонстрационную подпись формы после подключения.
7. Отправьте тестовую заявку: убедитесь, что сообщение пришло в нужный чат; отдельно проверьте ошибку при неверных настройках и повторную отправку после исправления. Реальная доставка в текущей поставке не проверена: реквизиты не предоставлены.

Обработчик проверяет origin, обязательные поля, согласие, honeypot, время заполнения и одноразовый Turnstile токен с hostname. Для повышенной нагрузки добавьте Cloudflare rate limiting. Успех возвращается только после подтверждения Telegram. При сетевом таймауте доставка может быть неопределённой — перед повтором проверьте чат. Персональные данные не пишутся в логи и localStorage. Секреты никогда не добавляйте в `src/` или переменные VITE_.

## Перед коммерческим запуском

Замените демо-тарифы, отзывы, график и шаблон политики реальными данными. Проверьте обещания услуг и обеспечьте их выполнение. Текущие фотографии — внешние Unsplash URL: для автономности и контроля загрузки замените собственными оптимизированными WebP/AVIF в `public/images`, подтвердите права на материалы. Шрифт Manrope загружается из Google Fonts; для автономного размещения сохраните лицензированные файлы локально. Настройте домен, HTTPS, индексирование и аналитику с требуемыми согласиями. Публикация Sites по умолчанию приватная, для клиентов нужен отдельно настроенный публичный доступ.

## Проверки

`npm test`: минимальный заказ, площадь, дополнительные услуги, единицы окон/мебели, некорректные входные данные, запрет чужого origin, защита от ложного успеха и honeypot. `npm run build`: строгая проверка TypeScript и production-сборка.
